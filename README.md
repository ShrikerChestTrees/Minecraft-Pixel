## Info
The game supports **Multiplayer** and **Creative**!

The game was created on Paint 3D
- Requirement from version MPAT1-MPR1.1:Download `Paint (Windows XP-11+)`/`Paint 3D (Windows 10-11+)`/`Adobe Photoshop 2020 (Windows 7-11+)`, `Adobe Photoshop Beta (AI) & other apps`
- Requirement from version MPR1.2-newer:Download `Paint.NET (Windows 10(21H2)-11+)`/`GIMP (Windows 7-11+)`

Version `Release 1.2-newer`

## How to install?

### 1.1.0 Beta 1 & older (Release 1.1-older)

1. Check if you have an __application to open `.zip` archives__/__`.png` image__ (Example: `7zip` & `Paint`).
2. Download launcher/latest version.
3. Open it.
4. And read file below launcher/version (`ENG - English`, `RU - Russian/Русский`)

### 1.1.0 & newer (Release 1.2-newer)

1. Check if you have an __application to open `.zip` archives & `.png`__/__`.pdn` image__ (Example: `7zip` & `Paint`/`Paint.NET`)
2. Download launcher/version.
3. If it's a launcher run `check_launcher_update.bat` so that it installs/finds latest version of launcher (There will be a link to page and auto-installation of archive)
4. If it's a version launch `.url` file (You can use Notepad to make sure it doesn't lead to a dangerous site) unzip archive to a convenient location for the game & simply open `.png`/`.pdn` image.
